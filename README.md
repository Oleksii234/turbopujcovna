# TurboPujcovna – semestrální projekt

Web fiktivní půjčovny aut v Ostravě (Ostravská univerzita, Computer Science).

**Ukázka:** https://oleksii234.github.io/turbopujcovna/

## Stránky
- `index.html` – úvod, carousel, služby, 3D scéna (Three.js)
- `vozovy-park.html` – tabulka vozů (DataTables), filtr, detail
- `cenik.html` – ceník, podmínky, pojištění
- `rezervace.html` – rezervační formulář s výpočtem ceny
- `o-nas.html` – o nás a FAQ
- `kontakt.html` – kontakt

## Technologie
Bootstrap 5.3, Bootstrap Icons, jQuery, DataTables, Three.js (CDN).
